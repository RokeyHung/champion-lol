# ARAM Random Discord Bot

A Discord bot built with Python that generates random ARAM team compositions using League of Legends champion data, exports images from HTML and converts them to PNG using html2image.

---

### 1. Clone project

```bash
git clone https://github.com/RokeyHung/champion-lol.git
```

### 2. Create virtual environment and install dependencies

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Or on bash:
source venv/Scripts/activate
pip install -r requirements.txt
```

### 3. Create .env file

Create a `.env` file in the project root directory and add your Discord bot token:

```bash
DISCORD_TOKEN="MTM..."
```
